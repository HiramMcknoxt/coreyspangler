# CoreySpangler.org — parked preview build

A post-election, city-council-centric redesign of Corey's site, parked on
GitHub Pages for review only:

**Preview: https://hirammcknoxt.github.io/coreyspangler/**

The coreyspangler.org domain is NOT pointed at this build. The live Wix
site remains live until Corey approves a switch. Nothing here touches
DNS or the Wix site.

## Build

    python3 ~/workspace/coreyspangler-build/build.py

renders this staging directory (~/workspace/coreyspangler-site/) from
page templates. Deploys are snapshot pushes of the staging dir, one
commit per deploy — full history, any prior version restorable.

## Copy discipline

Site copy follows the fidelity rules in Corey's second-brain guardrails
(07-guardrails.md): Ordinance 33 of 2026 is PENDING (third reading
Nov 16, 2026) and must never be described as passed; Corey is NOT for a
first-party/in-house ALPR system; Ordinance 21 of 2026 is "the first law
of its kind found anywhere," never a flat "first in the world"; the
§601.4 bylaw is stated as adopted (designation mechanism; no endorsement
bar); livestreaming was Resolution 49 of 2024, co-sponsored.
